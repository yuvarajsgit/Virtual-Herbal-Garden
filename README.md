# Virtual Herbal Garden 🌿

A secure, desktop-based information system built to centralize botanical taxonomy, environmental cultivation needs, and medicinal use profiles for various herbs and plants.

* **Repository Link:** [https://github.com/yuvarajsgit/Virtual-Herbal-Garden](https://github.com/yuvarajsgit/Virtual-Herbal-Garden)
  
##  Core Features

* **Secure User Portal:** Features functional login and registration screens linked to a database to securely verify and store user credentials.
* **Smart Auto-Complete Search:** Listens to user inputs in real time to instantly show a matching drop-down list of plants as you type.
* **Targeted Detail Extractions:** Dedicated action buttons allow users to fetch either full plant details, specific botanical names, or targeted medicinal uses.
* **Comprehensive Herb Profiles:** Displays exhaustive data records including Name, Botanical Name, Family, Category, Climate, Soil Type, Soil pH, and health benefits.
* **Seamless Window Layout:** Uses a clean card layout manager to switch instantly between welcome screens, authentication doors, and the main search hub.

---

##  Tech Stack
* **Language:** Java SE (Swing UI Framework)
* **Database Backend:** Relational Database Infrastructure (MySQL Server & JDBC Driver)
* **Architecture:** Event-Driven Architecture with `CardLayout` window management

---

##  How to Run it Locally

1. **Clone or Download** this repository.
2. Make sure your local MySQL database engine is active and configured with the `virtualherbalgarden` schema.
3. Import the project into your preferred Java IDE (such as NetBeans, Eclipse, or IntelliJ IDEA).
4. Ensure your project's build path includes the **MySQL Connector/J** library.
5. Run the **`VHG.java`** file to launch the application portal!
